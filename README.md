# micro:bit Kameralabor

Statische Web-App für iPad und Windows. In GitHub Pages: main / (root).

Die Bilder und Projekte liegen lokal im Browser. Vor dem Wechsel der Adresse Projektdatei (.json) aus dem alten Kameralabor speichern und unter der neuen Adresse wieder öffnen.

## micro:bit-Befehle

Die App sendet bei Erkennung `1` bis `10` über USB oder Bluetooth-UART. Zuordnung: `1` LEDs aus, `2` Herz, `3` Lächeln, `4` Links, `5` Rechts, `6` Hoch, `7` Häkchen, `8` Kreuz, `9` Quadrat, `10` Runter. Der Verbindungstest bleibt `PING` → `PONG`; ein Symbol wird mit `OK:<Zahl>` bestätigt.
